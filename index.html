What this dashboard does NOT cover (and how to access it)

True pocket listings are not in any public feed. By definition. The dashboard above only sees the public-facing slice of pre-market inventory — mostly MLS “Coming Soon” status (which is a regulated 24–48 hour pre-list window) plus the small public window into Compass Exclusives and a few self-published brokerage pages.

To access the actual private/pocket listings — the deals that never hit MLS — the only mechanism is an agent relationship at a brokerage with a private listing network. Specifically:

  • @properties Private Listing Network (PLN) — visible only to @properties agents and their registered buyer clients. Engage Rob Brannigan, Patty Wardlow / Wardlow Group, or the Bryan Bomba Group to get access.
  • Compass Private Exclusives — the full set (not just the public slice in this dashboard) is accessible through any of the 68 Compass agents in Downers Grove with a signed buyer agreement.
  • Coldwell Banker Exclusive Look — agent-only; requires buyer-broker agreement.
  • Local independent brokerages (Platinum Partners, RE/MAX Enterprises) — no corporate PLN, but they often see pocket inventory through informal agent-to-agent networks. The Glover Team is unusual in publishing a public “Private Listing” page; most don’t.
  • NAR “Multiple Listing Options for Sellers” (March 2025 policy) formally allows sellers to delay MLS syndication. This means more inventory is going the off-market route in 2026, which raises the value of having an agent inside one of the networks above.

Methodology & sources

Geographic scope: Downers Grove and 5 adjacent suburbs — Westmont, Hinsdale, Clarendon Hills, Lisle, Woodridge. Chosen because pocket inventory frequently crosses these boundaries and shares the same buyer pool.

Price scope: $400K–$1.5M. Q1 2026 DG median single-family was $607K; this band brackets the mid-to-upper market without going into deep luxury.

How the links work: Each link uses each site’s public Coming Soon URL pattern. Compass URLs include the $400K–$1.5M price filter because Compass’s URL schema is stable. Other sites have less stable URL filters — apply price/beds filter once after clicking, then save the search.

Sources for brokerage PLN classification: Compass press materials (compass.com/private-exclusives), @properties brokerage documentation, NAR March 2025 “Multiple Listing Options for Sellers” policy, and industry coverage of Clear Cooperation.

What to do if a link 404s: Each site occasionally renames URL paths. Go to the site’s main page, search the city, apply the Coming Soon status filter manually — that’s the canonical fallback. Then update the bookmark.
